# 📊 Sales Performance Dashboard (Excel)

## Project Overview

An interactive Excel dashboard built to analyze sales performance and turn raw data into actionable business insights.

---

## Dashboard Features

* KPI Cards
* Sales by Region
* Sales by Product Category
* Top Sales Representatives
* Customer Type Analysis
* Sales Channel Comparison
* Monthly Sales Trend
* Interactive Year Slicer
* Key Insights Panel

---

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Visualization
* Dashboard Design

---

## Key Insights

* North region achieved the highest sales.
* Clothing was the top-performing category.
* David ranked as the top sales representative.
* Returning customers generated slightly higher revenue.
